# Lista 02 — DDL na prática (ALTER TABLE)

Dois exercícios praticando `ALTER TABLE`: adicionar coluna, renomear coluna, alterar tipo/tamanho, remover restrição, renomear tabela.

| Exercício | Tabela | O que pratica |
|---|---|---|
| `ex001` | produtos → itens | ADD, RENAME COLUMN, MODIFY, DROP INDEX, RENAME TO |
| `ex002` | clientes | ADD, ADD CONSTRAINT CHECK, RENAME COLUMN, MODIFY, DROP INDEX |

Arquivos numerados (`01-`, `02-`, `03-`) porque a ordem de execução importa nesse caso.
